# PRD: JOTO 智能选题与一键 5 篇候选文章生成

## Summary
用户只选择一个产品,系统自动判断这个产品最适合从哪些内容角度切入,并生成 5 篇不同角度的 JOTO 白底公众号文章。系统支持从用户提供的文章链接/正文中学习新的写作风格,后续生成时随机混用官方 JOTO 风格与学习风格。生成完成后,用户可把 5 篇候选模拟发送给产品经理邮箱,由产品经理选择发布哪篇。

## Product Requirements
- 主流程改为“选产品 -> 自动生成 5 篇”,角度和风格不再需要用户手动选择。
- 系统只基于产品资料判断内容角度,不联网判断市场或竞品。
- 成熟赛道/明显竞品产品优先生成竞品、价格、生态、替代方案、为什么选择我们等角度。
- 新概念/低认知产品优先生成为什么需要、使用场景教育、产品启蒙、产品介绍等角度。
- 每次生成 5 篇,5 篇角度必须不同,每篇文章保存系统选择该角度的原因。
- 顶部新增“风格库”入口,支持通过链接或粘贴正文学习写作风格。
- 学习结果保存在当前浏览器 localStorage,后续生成时和 JOTO 官方风格随机混用。
- 顶部新增“邮箱”入口,管理产品经理邮箱。第一版只做模拟发送,不真实投递。
- 批次页新增“发送给产品经理”按钮,模拟邮件包含 5 篇候选的标题、角度、使用风格、摘要和 Review 链接。

## Implementation Plan
- 新增 `TopicPlan`,记录每篇候选的角度、原因、prompt 指令。
- 新增 `LearnedWritingStyle`,记录从链接/正文学习出的写作风格。
- 新增 `EmailSettings`,记录产品经理邮箱和模拟发送历史。
- 扩展 `Article.generationMeta`,记录自动生成模式、角度原因、使用风格来源。
- 新增 topic planner prompt 和本地兜底规则,生成 5 个不同选题。
- 产品页主按钮改为“随机生成 5 篇”,生成页在 `auto-five` 模式下先生成 5 个 `TopicPlan`,再并发生成正文。
- `/api/generate` 支持临时学习风格 profile,并把 `TopicPlan` 注入 prompt。
- 新增 `/api/styles/learn`,从链接或粘贴正文提炼写作风格。
- 新增 `/api/email/send-batch` mock 接口。
- 所有自动生成文章默认 `layoutTheme: "joto"`。

## Test Plan
- 只选产品即可进入生成页。
- 自动生成任务数量固定为 5。
- 5 篇文章角度不重复。
- NotebookLM 类产品会优先出现竞品、生态、价格、替代方案类角度。
- 新概念产品会优先出现用户教育、为什么需要、使用场景类角度。
- 没有学习风格时,文章使用 JOTO 官方风格。
- 有学习风格时,5 篇文章随机混用官方风格和学习风格。
- 链接学习失败时可粘贴正文兜底。
- 学习风格刷新后仍存在。
- 所有文章在 Review、Batch、Dashboard 入口都保留 JOTO 白底公众号模板。
- 邮箱管理可保存默认产品经理邮箱。
- mock 发送成功后记录发送历史。

## Assumptions
- 第一版不联网判断产品市场和竞品,只使用用户提供的产品资料。
- 邮件第一版为模拟发送,不真实投递。
- 学习风格保存在当前浏览器 localStorage。
- 旧手动角度/风格流程暂时保留,避免破坏已有功能。
